# Planulix v1.0.0

Release page: https://github.com/pyatkovpetr/Planulix/releases/tag/v1.0.0

## Assets

- `Planulix-macOS-v1.0.0.zip` — macOS desktop app.
- `Planulix-Android-v1.0.0.apk` — Android APK.
- `SHA256SUMS.txt` — checksums for macOS ZIP and Android APK.
- `planulix-gateway-linux-amd64.tar.gz` / `planulix-gateway-linux-arm64.tar.gz` — Linux Gateway builds produced by GitHub Actions for the tag.

## Highlights

- Codex CLI support via ChatGPT/OAuth login:
  - OAuth callback URLs with `id_token` are parsed correctly.
  - ChatGPT/OAuth mode defaults to the Codex CLI model instead of forcing API-only `gpt-5.2-codex`.
  - Managed and detached Codex chats return assistant output directly to Planulix.
- Desktop chat polish:
  - Copy buttons and right-click copy menu for session/chat messages.
  - Cleaner Codex output in session transcript views.
  - Saved workspace fallback when the explorer project is not open.
- Gateway improvements:
  - Codex exec flags updated for recent Codex CLI versions.
  - OAuth submit race handled when CLI already completed authentication.
  - Codex readiness can be detected from OAuth artifacts under `~/.codex`.

## Install

### macOS

1. Download `Planulix-macOS-v1.0.0.zip`.
2. Unzip it.
3. Open `Planulix.app`.

If macOS blocks opening the app, right-click `Planulix.app` in Finder and choose **Open**.

### Android

1. Download `Planulix-Android-v1.0.0.apk`.
2. Open the APK on the device.
3. Allow installation from the selected browser/file manager if Android asks.

### Gateway

Recommended VPS install/update:

```bash
curl -fsSL https://raw.githubusercontent.com/pyatkovpetr/Planulix/main/scripts/install_gateway_remote.sh \
  | AUTH_TOKEN='your-secret-token' bash -
```

Manual build:

```bash
cd server
go build -o planulix-gateway .
AUTH_TOKEN='your-secret-token' ./planulix-gateway
```

## Verification

The release was built locally with:

```bash
flutter build apk --release
flutter build macos --release --no-tree-shake-icons
cd server && go test -count=1 ./...
```

Use `SHA256SUMS.txt` to verify downloaded desktop/mobile assets.
