# Planulix v1.1.0

Release page: https://github.com/pyatkovpetr/Planulix/releases/tag/v1.1.0

## Assets

- `Planulix-macOS-v1.1.0.zip` - macOS desktop app.
- `Planulix-Android-v1.1.0.apk` - Android APK.
- `SHA256SUMS.txt` - checksums for macOS ZIP and Android APK.
- `planulix-gateway-linux-amd64.tar.gz` / `planulix-gateway-linux-arm64.tar.gz` - Linux Gateway builds produced by GitHub Actions for the tag.

## Highlights

- Agent control center with repository, branch, worktree, runtime, cost, duration, Git status and failure details.
- Saved task specifications and the `Make Plan` flow before starting an agent session.
- Explicit agent manifests for installation, readiness, auth, history, launch and capability discovery.
- Writable Git workspaces after GitHub clone/upload, including `.git` permission repair and clearer commit/push diagnostics.
- Codex session reconciliation to suppress duplicate and phantom sessions.
- Markdown chat rendering with fenced code blocks, selectable code and copy actions.
- OpenCode setup now checks actual CLI readiness instead of only installer exit status.
- Connection wizard accepts tokenless local gateways, validates `/healthz` without waiting for session discovery and saves without blocking the UI.
- Session creation resets hidden list scopes so newly created sessions remain visible.

## Install

### macOS

1. Download `Planulix-macOS-v1.1.0.zip`.
2. Unzip it.
3. Open `Planulix.app`.

If macOS blocks opening the app, right-click `Planulix.app` in Finder and choose **Open**.

### Android

1. Download `Planulix-Android-v1.1.0.apk`.
2. Open the APK on the device.
3. Allow installation from the selected browser/file manager if Android asks.

### Gateway

Recommended VPS install/update:

```bash
curl -fsSL https://raw.githubusercontent.com/pyatkovpetr/Planulix/main/scripts/install_gateway_remote.sh \
  | AUTH_TOKEN='your-secret-token' bash -
```
